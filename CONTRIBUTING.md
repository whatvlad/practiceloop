# Contributing

Humans and AI agents follow the same rules in [AGENTS.md](AGENTS.md):

Issue (assign yourself) -> branch from `main` -> commit and push -> PR -> review
by the other developer -> green CI -> squash merge.

Use Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`,
`chore:`). Run the README checks before opening a PR. Coordinate API, schema,
auth and architecture changes with the other developer first.
