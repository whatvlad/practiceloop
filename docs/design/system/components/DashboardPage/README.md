The `/dashboard` route. It does three jobs in order: show the three counters, let the user start a problem (topic chips, difficulty scale, one primary Generate Problem button), and list the three most recent problems with a link to the full history.

The consumer provides the profile counts, the current selections (default: last used) and the last three history items. Generating navigates to `/practice` with the new problem already saved.

The page title is a `display-md` sentence with one italic phrase. Keep the italic to one phrase per page.
