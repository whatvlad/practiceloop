Difficulty is always one of five named levels: 1 Basic, 2 Easy, 3 Medium, 4 Hard, 5 Advanced.

The consumer provides the selected level (1–5). Use the segmented scale where the user chooses; use the five-dot indicator (`pl-dots`) wherever a problem's difficulty is shown, next to the text "3/5" so the dots are never the only signal.

- Selected segment fills `action`, matching the selected topic chip.
- Dots: filled in `ink`, empty with a `control-border` ring.
- Text for assistive tech: "Difficulty 3 of 5".
