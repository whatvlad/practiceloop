The MVP profile shows three numbers: problems generated, problems attempted, correct answers. Nothing else belongs in a stat tile in this release (no streaks, ranks or trends).

The consumer provides the label, the integer value, and optionally the denominator and a 0–100 fill for the bar. Numerals are `display-lg`-family serif at 64px; labels are `label` eyebrows.

The bar is monochrome (`ink` on `surface-raised`); do not colour it green or red.
Sample numbers in previews are illustrative.
