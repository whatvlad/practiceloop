How it works

Four taps from a topic to a solved problem.

1

Choose a topic

Basic integrals, substitution, by parts, rational and trigonometric.

2

Set the difficulty

Five levels, from Basic to Advanced.

3

Type your answer

Write 3pi, sqrt(3) or pi/4 + 2. Equivalent forms all count.

4

Learn, then loop

Reveal the answer or the full solution, then generate the next problem.

The difference

Rules, not guesses.

Generated from structures

Problems are built from predefined mathematical rules, not written freehand by a language model.

Verified symbolically

Every answer is calculated and checked by a symbolic mathematics engine before you see the problem.

Checked by equivalence

1/2 and 2/4 are the same answer. We compare mathematics, not text.
