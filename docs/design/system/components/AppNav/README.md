The app bar carries the wordmark, the signed-in routes (Dashboard, Practice, History, Profile) and the account area with Log out. The signed-out bar (landing, login) shows the logo and a single `secondary` Sign in button instead.

The consumer provides the current route (marked with `aria-current="page"`) and the user's initial for the avatar.

- 68px tall, `canvas` background, `line` hairline underneath. Active link sits on `surface-raised`.
- The logo is the loop mark (a ring with a centre point) plus "PracticeLoop" in the display serif. It is original to this system, drawn inline in `currentColor`; there is no separate logo file.
