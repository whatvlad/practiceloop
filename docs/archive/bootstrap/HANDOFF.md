# Handoff format

Use a GitHub Issue/PR comment for live coordination; this file is the reusable
format, not a shared-file mutex. Avoid raw credentials and personal user data.

```text
Agent:
Accountable human:
Issue / PR:
Branch / base and head commit:
Scope / files touched:
Current status:
Completed behavior:
Exact verification commands and observed results:
Checks not run and why:
Uncommitted changes / recovery instructions:
Open findings, risks and architectural questions:
Dependencies / overlapping ownership:
Next concrete action:
Review / human approval / merge state:
```

Bootstrap handoff is in STATUS.md and docs/development/SETUP_REPORT.md. No remote
or GitHub Issue exists until owner approval and successful publication.
