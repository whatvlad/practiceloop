# Аналитическая геометрия: план локальной реализации

> Исполнитель: использовать `superpowers:executing-plans` для последовательной
> работы. Других агентов не запускать без отдельного разрешения пользователя.

**Цель:** расширить существующую практику «Vectors, areas and volumes» задачами
по образцу сборника, трёхуровневым выбором и пошаговой интерактивной графикой.

**Архитектура:** сохранить существующий генераторный движок и неизменяемые
исторические версии. Строить публичный рисунок из данных условия, а рисунки
шагов передавать только при раскрытии решения; использовать текущие компоненты
практики, Three.js и проверку структурированных ответов.

**Технологии:** Python, SymPy, Pydantic, pytest, React, TypeScript, Three.js,
Vitest и браузер. Новые зависимости не добавлять без обоснованной необходимости.

**Спецификация:** `docs/superpowers/specs/2026-11-11-analytic-geometry-design.md`.

## Общие ограничения

- Изменения и тесты выполняются локально. Последующие push и развёртывание
  подготовить без GitHub Actions; каждый push требует подтверждения владельца.
  GitHub Project без отдельного разрешения не изменять.
- Пользователь подтвердил локальную работу вне очереди без отдельного Issue
  и отсутствие параллельного редактирования общих файлов другим агентом.
- Не менять зафиксированные ADR-008 интерфейсы, PRNG и формат кодов без
  необходимой поправки ADR; старые версии и исторические результаты сохранять.
- Три уровня для каждого доступного типа; разные математические действия,
  а не просто большие числа. Некорректные векторные выражения сейчас исключены.
- № 75–77 сборника пока не реализованы; они не входят в утверждение о покрытии
  текущих десяти типов и остаются возможными следующими расширениями.
- Общий лимит визуального payload и конечность координат проверяются на границе;
  условие не передаёт решение. Рисунки соответствуют конкретной задаче.
- Обычные локальные seed-sweep ограничены проектом; 1000 семян — только
  итоговый локальный прогон. При недоступных проверках сообщать о пропуске.
- Выполнять этапы последовательно в этом рабочем дереве; не делать коммиты
  автоматически.

## Особое внимание при проверке

1. Основание высоты может лежать вне границ треугольника: визуализировать
   продолжение плоскости и правильную перпендикулярность.
2. 2D-проекция пространственной фигуры не всегда сохраняет углы и длины:
   обозначать вид и не делать неверных визуальных утверждений.
3. Ответ может быть вектором: сверять все три координаты и принимать
   эквивалентные значения, не раскрывая ответ до запроса.
4. Исторические коды и старые уровни 4–5 должны открываться с исходным
   условием и ответом, хотя новый экран выбора предлагает три уровня.
5. Несколько 3D-сцен и отсутствие WebGL не должны нарушать решение,
   управление или доступность карточки.
